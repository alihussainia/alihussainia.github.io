# Personal Portfolio Project

This is a personal portfolio project that showcases my skills, experiences, and completed projects. The website is structured to provide a user-friendly experience and is built using HTML, CSS, and JavaScript.

## Project Structure

The project consists of the following files and directories:

```
personal-portfolio
├── src
│   ├── index.html         # Main entry point of the website
│   ├── about.html         # About me page
│   ├── projects.html      # Projects showcase page
│   ├── contact.html       # Contact information page
│   ├── css
│   │   └── styles.css     # Styles for the website
│   ├── js
│   │   ├── main.js        # Main JavaScript file
│   │   └── utils.js       # Utility functions
│   ├── components
│   │   ├── header.js      # Header component
│   │   └── footer.js      # Footer component
│   └── data
│       └── projects.json   # Project data
├── package.json           # npm configuration file
├── .gitignore             # Git ignore file
└── README.md              # Project documentation
```

## Features

- **Responsive Design**: The website is designed to be responsive and accessible on various devices.
- **Dynamic Content**: Projects are loaded dynamically from a JSON file, allowing for easy updates.
- **Interactive Elements**: JavaScript is used to enhance user interaction and navigation.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd personal-portfolio
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Open the `index.html` file in your browser to view the portfolio.

## Usage

- Navigate through the website using the header links.
- Visit the "About" page to learn more about me.
- Check out the "Projects" page to see my work.
- Use the "Contact" page to reach out for inquiries or collaborations.
